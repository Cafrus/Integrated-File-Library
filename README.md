##🎉 Integrated File Library v1.0.0 — First Release

First open-source release. Feel free to try it, give feedback, and contribute!

##✨ 功能特性
##✨ Features

- 🌳 **树形目录管理** —— 任意层级，一屏看清全部资料
- 🌳 Tree directory management — Unlimited levels; view all your materials on one screen
- 🖱 **拖拽入库** —— 从资源管理器拖文件/文件夹自动归档
- 🖱 Drag-and-drop import — Drag files/folders from File Explorer to archive them automatically
- 📚 **版本管理** —— 同名文件不覆盖，自动存历史版本
- 📚 Version management — Files with the same name are not overwritten; historical versions are saved automatically
- 👁 **内嵌预览** —— 图片、txt、代码直接看
- 👁 Built-in preview — View images, txt files, and code directly
- 📦 **一键导出** —— ZIP / 目录清单 TXT / JSON 任选
- 📦 One-click export — Choose ZIP / directory list TXT / JSON
- 🧩 **列自定义** —— 表头想加什么加什么
- 🧩 Custom columns — Add any columns you want to the table header
- 🔍 **筛选搜索** —— 关键词快速定位
- 🔍 Filter and search — Quickly locate items by keyword
- 💾 **完全本地离线** —— 数据全在自己硬盘
- 💾 Fully local and offline — All data stays on your own hard drive

##📦 Download
